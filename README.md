# 🥋 HAMRA ANNABA — Section Karaté-Do (Club Fondé en 1944)

Site web officiel, moderne et responsive pour la section de **Karaté-Do** du prestigieux club **Hamra Annaba** (Annaba, Algérie).

---

## 🌟 Caractéristiques du Projet

- **Direction Artistique Club :** Rouge officiel Hamra (`#DC2626`), Blanc pur et noir carbone dojo avec ambiance martiale prestigieuse (normes *UI-UX Pro Max* & *Unslop*).
- **Logo Officiel Récupéré :** Blason historique officiel de Hamra Annaba intégré en haute fidélité (`/hamra-annaba-logo.png`).
- **Photographies Réalistes d'Enfants :** 5 photos authentiques d'enfants et adolescents en dojo, kata et kumité sous protections WKF.
- **Réseau des 4 Salles à Annaba :**
  1. *Complexe Colonel Abdelkader Chabou* (Centre-ville)
  2. *Salle Omnisports Pont Blanc* (Annaba Centre)
  3. *Dojo Omnisports El Bouni* (Complexe de proximité)
  4. *Salle Martiale Plaine Ouest* (Sidi Achour)
- **Tarif Fixe & Transparent :** **2 000 DA / mois**.
- **Dossier d'Inscription Complet Intégré :**
  - Extrait de naissance
  - Deux (02) photos d'identité récentes
  - Certificat médical d'aptitude sportive
  - Autorisation paternelle / parentale avec formule légale
- **Formulaire de Pré-Inscription & Récépissé :**
  - Renseignement complet de l'élève et du parent (nom, prénom, profession du parent, tél, email).
  - Génération automatique de numéro de dossier (`HAMRA-KR-2026-XXXX`).
  - Bouton de confirmation WhatsApp direct avec message pré-rempli vers le club.
  - Récépissé imprimable conforme.

## 🚀 Hébergement sur Vercel (Chez vous)

Le projet est 100% prêt pour Vercel (avec fichier `vercel.json` configuré).

### Option 1 : Déploiement en 1 clic via le Dashboard Vercel
1. Déposez ce dossier sur votre compte GitHub (ou GitLab / Bitbucket).
2. Connectez-vous sur [vercel.com](https://vercel.com).
3. Cliquez sur **« Add New Project »** et sélectionnez votre dépôt.
4. Vercel détecte automatiquement le framework **Vite** :
   - **Build Command :** `npm run build`
   - **Output Directory :** `dist`
5. Cliquez sur **« Deploy »**. Votre site sera en ligne en moins de 30 secondes !

### Option 2 : Déploiement via la CLI Vercel
```bash
# Installer Vercel CLI (si ce n'est pas déjà fait)
npm install -g vercel

# Lancer le déploiement
vercel

# Pour déployer directement en production :
vercel --prod
```
